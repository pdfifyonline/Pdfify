PDFify site - upload guide
==========================
1. Copy EVERYTHING in this folder (all folders and files) into the root of your GitHub repository, replacing old files with the same name.
2. Commit and push with GitHub Desktop and wait about one minute for the website to update.
3. Open https://pdfify.online/upload-check/ - every line must have a green tick.
4. Open FILE-LIST.txt for the full list of files.
5. Accounts: read SETUP-ACCOUNTS.txt (about 10 minutes). You only edit config.js and upload it. The files SETUP-ACCOUNTS.txt and supabase-setup.sql are for you, they do not need to be uploaded.
6. To change the logo, menu, footer or email on ALL pages, tell me or re-run the builder; each page contains its own copy of the layout.
