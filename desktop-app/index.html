Install PDFify on your computer and open it like a normal app, in its own window.

If the button does not work

  • Chrome or Edge on a computer: open the browser menu (⋮) and choose Install PDFify.
  • iPhone or iPad (Safari): tap Share, then Add to Home Screen.

The installed app is the PDFify website in its own window. It needs an internet connection to load the tools the first time.
